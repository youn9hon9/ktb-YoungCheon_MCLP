# 영천시 횡단보도 좌표 수집 앱

Streamlit 지도에서 횡단보도를 클릭하고 좌표를 저장하는 도구입니다.

## 실행

Python 3.11 이상에서 저장소 폴더로 이동한 뒤 실행합니다.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py
```

브라우저에서 `http://localhost:8501`을 엽니다. Codespaces에서는 포트 8501의 미리보기를 사용합니다.

## 좌표 수집과 저장

1. 기존 좌표는 파란색 마커로 표시됩니다.
2. 지도에서 횡단보도를 클릭합니다.
3. 지도 아래의 좌표를 확인하고 **이 좌표 저장** 버튼을 누릅니다.
4. **CSV 다운로드**로 전체 좌표를 내려받을 수 있습니다.

첫 실행은 `data/영천시/영천시_횡단보도_좌표.csv`를 읽습니다. 저장 버튼을 누르면 작업 사본인 `data/횡단보도_좌표.csv`에 기록하며, 다음 실행부터 이 파일을 우선 읽습니다. 원본 수집 데이터는 변경하지 않습니다. 화면 조회나 다운로드만으로 파일을 덮어쓰지 않습니다.

다른 저장 파일을 사용하려면 `CROSSWALK_CSV_PATH` 환경변수를 지정하세요. 이 앱은 개인 수집 작업을 위한 파일 기반 도구이며 여러 사용자의 동시 저장을 보장하는 데이터베이스는 사용하지 않습니다.

## 행정경계와 격자

현재 저장소에는 원래 코드가 요구하던 행정경계 GeoJSON이 없습니다. 경계 없이도 기본 지도에서 좌표를 수집할 수 있습니다.

WGS84 경도·위도 좌표의 Polygon/MultiPolygon GeoJSON을 사이드바에서 업로드하면 경계와 탐색 격자가 나타납니다. 계속 사용하려면 `data/행정동경계/yeongcheon_dong_boundary.geojson`에 저장하세요. 업로드한 파일은 세션에서만 사용합니다.

격자는 기존 수집 방식과 같은 **0.0045도 간격**의 탐색 보조선이며, 정확한 500m 정사각형이 아닙니다. 지도 타일을 불러오려면 인터넷 연결이 필요합니다.

## 검증

```bash
.venv/bin/python -m unittest discover -s tests -v
```

경계 파일 없이 실행, 실행 디렉터리 변경, 좌표 저장·재접속·중복 방지, 잘못된 CSV 및 저장 실패 처리를 확인합니다. 테스트는 임시 저장 파일을 사용합니다.
