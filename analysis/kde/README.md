# 영천시 KDE 재구성

원래 KDE 코드·격자 결과가 저장소에 없어, 보고서의 최종 중요도와 현재 POI를 사용해 새로 계산한 시각화입니다. 과거 보고서와 동일한 결과를 재현한 것이 아닙니다. 머신러닝을 다시 학습하지 않습니다.

## 실행

저장소 루트에서 실행합니다.

```bash
.venv/bin/python -m pip install -r analysis/kde/requirements.txt
.venv/bin/python analysis/kde/reconstruct.py
.venv/bin/python -m unittest discover -s analysis/kde -v
```

한글 폰트는 로컬의 Malgun Gothic 또는 Noto Sans CJK KR을 사용합니다.

## 이번 계산에서 정한 가정

- POI: `data/영천시/영천시_POI_통합.csv`. 좌표는 WGS84 경도·위도로 읽고 EPSG:5179로 변환합니다.
- 시 경계와 읍면동 경계: 사용자가 제공한 `bnd_sigungu_37070_2025_2Q.zip`, `bnd_dong_37070_2025_2Q.zip`.
- 대역폭은 보고서 PDF 10쪽 표 3의 중요도 × 1,000m입니다. 가우시안 커널의 표준편차로 해석합니다. 원래 코드의 커널 정의는 확인되지 않았습니다.
- 계산 격자는 EPSG:5179의 25m 셀 중심입니다. 최소 대역폭 35.8m를 고려했습니다. 25m는 계산 간격이며, 원자료의 공간 정확도를 뜻하지 않습니다.
- 각 유형의 KDE를 `sum(exp(-r²/(2h²))) / (n × 2πh²)`로 계산합니다. 유형 내 적분이 1인 확률밀도를 합산한 뒤 영천시 내부 최솟값·최댓값으로 0–1 정규화합니다. 각 유형의 중요도는 대역폭에만 적용하며, 합산 시 다시 곱하지 않습니다. 시설 개수가 많은 유형에 비례한 추가 가중치도 주지 않습니다.
- 원래 POI 좌표에서 직접 계산하며, 계산량을 줄이기 위해 각 점의 가로·세로 ±5h까지만 평가합니다. 이로 인한 연속 가우시안 질량 누락은 유형당 0.000115% 미만입니다.
- 대응 후 같은 유형·경도·위도인 중복 행을 제거합니다. 동일 건물의 별도 시설도 같은 좌표일 수 있으므로 이 기준은 이번 재구성의 선택이며, 실제 중복 시설임을 검증한 것은 아닙니다.
- 영천시 내부 POI만 사용하며 결과는 시 경계 밖을 마스킹합니다. 인접 시군의 시설 자료는 없고, 경계 보정도 적용하지 않습니다. 경계 주변 밀도가 과소평가될 수 있습니다.

### 유형 대응

이름이 같은 유형은 그대로 사용합니다. 다음 대응은 이번 재구성에서 둔 가정이며, 당시 분류표를 확인한 결과가 아닙니다.

| CSV 유형 | 보고서 유형 | 판단 |
| --- | --- | --- |
| 의료기관 | 의료시설 | 명칭 대응 |
| 미용업 | 미용실 | 명칭 대응 |
| 문화시설 | 문화공연시설 | 범위가 다를 수 있는 근사 대응 |
| 어린이집,유치원 및 지역아동센터 | 아동돌봄시설 | 두 유형을 합침 |
| 카페, 부동산 | 없음 | 중요도가 없어 제외 |
| 대응 자료 없음 | 청소년복지시설 | 다른 시설로 대체하지 않고 제외 |

정확히 일치하는 이름만 사용한 결과와 비교하는 등 분류 민감도 검증은 아직 수행하지 않았습니다.

## 산출물

- `output/yeongcheon_kde_wide.png`: 영천시 전체와 도심 확대 지도. 동일한 전역 점수·색상 기준을 사용합니다. 낮은 밀도를 보기 위해 색상만 제곱근 스케일로 표시하며 계산값은 바꾸지 않습니다.
- `output/kde_grid.npz`: 투영좌표 x/y, 밀도(m⁻²), 정규화 점수, 경계 마스크, CRS, 격자 간격. 경계 밖은 NaN입니다.
- `output/category_summary.csv`: 유형별 사용 지점 수, 중요도, 대역폭, 경계 내부 밀도 적분.
- `output/included_poi.csv`: 계산에 실제 사용한 POI.
- `output/metadata.json`: 제외·중복 건수, 유형 대응, 원자료 SHA-256.

이 점수는 실제 유동인구 수, 그늘막 수요 확률, 설치 효과의 측정값이 아닙니다.
